# Exercises on Arrays, Class and Object, and Wrapper Classes

## Project description
This project contains practical Java exercises covering 1D and 2D arrays, wrapper classes (`Integer`), and Object-Oriented Programming concepts:

* **Exercise 1 (`CourseNumbersArray`):** Initializing an integer array of course numbers, dynamically copying elements into a larger array to add a new course, and searching for specific course IDs.
* **Exercise 2 (`DogShelter`):** Using a static `Integer[]` wrapper array to manage, update, delete, and display dog counts per breed.
* **Exercise 3 (`BankAccount`):** Simulating a bank account with deposit validation, balance-checked withdrawals, and a recorded transaction history array.
* **Exercise 4 (`Student` & `ManageStudent`):** Manipulating arrays of `Student` objects—including finding the oldest student, counting adults, calculating average grades, searching by name, sorting via Bubble Sort, detecting duplicate names, dynamically resizing arrays, and finding the top student per classroom using a 2D array (`Student[][]`).
